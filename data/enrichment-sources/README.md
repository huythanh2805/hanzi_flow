# External enrichment snapshots

Raw downloads are ignored by Git. `downloads.json` pins their exact URL, byte count and SHA-256. Selected source-attributed records and coverage reports are retained under `data/imported/` for repeatable offline database imports.

Sources inspected before use:

- CC-CEDICT, MDBG/community: https://www.mdbg.net/chinese/dictionary?page=cc-cedict. CC BY-SA 4.0. Only the explicitly provided bulk download is used; no dictionary-page scraping.
- Vietnamese Wiktionary contributors, extracted by Wiktextract/Kaikki: https://kaikki.org/viwiktionary/rawdata.html. Dump 2026-10-02, extraction 2026-10-21. CC BY-SA / GFDL as published by Wiktionary. Source page links are preserved for each selected sense. Romanizations, redirects without glosses, and unrelated languages are excluded.
- Tatoeba contributors: https://downloads.tatoeba.org/exports/per_language/. Snapshot 2026-10-24. Chinese, English and Vietnamese sentences and direct translation links. Text is CC BY 2.0 FR (or CC0 for sentences explicitly in the CC0 export). Retain individual sentence IDs, owners and source URLs; do not import unowned records where attribution is unavailable. No audio is imported.

Licenses: https://creativecommons.org/licenses/by-sa/4.0/ ; https://creativecommons.org/licenses/by/2.0/fr/ ; https://creativecommons.org/publicdomain/zero/1.0/ ; https://vi.wiktionary.org/wiki/Wiktionary:Bản_quyền .

These are community dictionaries/corpora, not a claim of professional review. Band checks cover vocabulary against the pinned GF 0025-2021 list; they do not certify a complete grammatical proficiency level. Unmatched and ambiguous dictionary matches are reported. On 2026-10-25 the owner explicitly authorized automatic translation for missing content: the offline Argos/OPUS-MT fallback is labeled machine-unreviewed, with model hashes and original inputs retained. Chinese examples are never generated by this fallback.
